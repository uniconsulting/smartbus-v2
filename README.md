# Dionq | SmartBus v2.0

Актуальная версия сайта SmartBus на Next.js 15 и React 19. Главная страница заново собрана по макетам заказчика: BICUBIK и Garet, фирменная палитра, адаптивная геометрия, анимации секций и счётчиков, закрепляемый стеклянный хедер. Статьи, документы, контакты, SEO, аналитика и уведомления доступны для управления в панели редактора.

Основная ветка — `prod`. Дизайн-система и правила реализации описаны в [design/README.md](design/README.md), исходные макеты находятся в [design/references](design/references), бренд-материалы — в [design/brand](design/brand).

Для первого запуска на VPS администратору понадобятся зашифрованный архив из каталога `deploy/` и ключ, полученный отдельно. [Распаковка архива](deploy/SMARTBUS-INITIAL-DATA.md) · [Установка на VPS](docs/vps-handoff.md).

## Локальный запуск

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

Сайт откроется по адресу `http://localhost:3000`.

Для проверки production-сборки:

```bash
pnpm run build
pnpm exec next start --hostname 127.0.0.1 --port 3012
```

Production-сборка хранится в `.next-build`, dev-кэш — в `.next`. На чистом checkout сначала выполните сборку: она создаёт типы маршрутов для проверки TypeScript.

## Структура

- `/` — услуги, автопарк, приложение для сотрудников, этапы работы, география и форма заявки;
- `/articles` — опубликованные материалы о корпоративных перевозках;
- `/documents` — реквизиты, пользовательское соглашение, политика обработки персональных данных, согласие для формы и политика cookie;
- `/contacts` — контакты компании и карта офиса.

Исходные материалы для нового сайта находятся в `lib/articles.ts`. После первой правки редакции хранятся в SQLite. Сердечки на карточках и страницах статей сохраняют отметку в браузере посетителя; общедоступного счётчика лайков нет.

## Управление сайтом

Панель доступна по адресу `/adpanel`. При восстановлении закрытого стартового архива учётная запись владельца уже настроена. Для каждого дополнительного редактора создайте отдельный логин на сервере приложения. Команда ниже записывает случайный пароль в новый файл с правами владельца. Файл должен находиться вне репозитория и публикуемых каталогов.

```sh
pnpm admin:account editor /private/path/smartbus-editor.txt
```

Чтобы заменить пароль и завершить сессии редактора, повторите команду с новым именем файла и флагом `--reset`. Сессия действует 12 часов. Для внешнего доступа панели требуется HTTPS.

В «Статьях» редактор работает с абзацами, заголовками, списками, обложкой и SEO материала. Обложку можно выбрать из библиотеки или загрузить своей фотографией. «Сохранить черновик» оставляет текущую публикацию доступной. «Опубликовать» обновляет открытый сайт. В «Документах» можно редактировать каталог, текстовые документы и загружать PDF до 10 МиБ. «Контакты» меняют публичные телефоны, почту и адрес. «SEO» управляет метаданными и индексацией основных страниц. Карта сайта доступна по адресу `/sitemap.xml`.

Данные SQLite, каталоги файлов `pdfs/` и `article-covers/`, а также локальный ключ шифрования интеграций находятся в `SMARTBUS_DATA_DIR`. По умолчанию это каталог `data` рабочего проекта. При развёртывании задайте постоянный каталог на записываемом диске одного сервера и сохраняйте его между выпусками. Для резервной копии остановите приложение и скопируйте каталог целиком либо используйте штатный SQLite backup и отдельную копию файлов. Если ключ шифрования задан через `SMARTBUS_INTEGRATION_KEY`, храните резервную копию этого секрета отдельно.

## Заявки и аналитика

Форма передаёт заявку в `POST /api/lead`. Сначала сервер сохраняет её в SQLite, затем передаёт уведомление выбранному боту. При недоступности мессенджера менеджер видит результат и может повторить доставку в разделе «Интеграции». Ранее отправленные уведомления и старый файл `data/leads.jsonl` не используются для вычисления новой воронки.

При переносе из закрытого стартового архива MAX уже настроен: проверьте подключение в «Интеграциях». Для настройки новой беседы MAX добавьте в неё бота, укажите в панели токен и ID группы и сохраните настройки. Также можно задать `MAX_BOT_TOKEN` и `MAX_CHAT_ID` на сервере. Группа имеет приоритет перед личным получателем `MAX_USER_ID`. Поле токена при следующем открытии формы остаётся пустым. Для Telegram предусмотрены отдельный режим и параметры `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

В «Аналитике» доступны источники и кампании, просмотры, действия, принятые заявки и конверсия визитов. Действия учитываются после разрешения аналитики. Заявка без этого разрешения попадает в общее число без истории визита. Фильтры дают отчёт по датам и источнику.

## Cookie и карта

На главной уведомление о cookie размещено внутри Hero и закрепляется при прокрутке. На внутренних страницах оно сразу доступно внизу экрана. «Понятно» сохраняет только необходимые cookie. Разрешить встроенную карту и аналитику или изменить выбор можно через «Настройки cookie» в футере. Если выбраны только необходимые, карта на странице контактов загрузится после отдельного нажатия «Показать карту». Яндекс.Метрика пока не подключена. Юридические страницы доступны по адресам `/documents/terms`, `/documents/privacy`, `/documents/consent` и `/documents/cookies`.

## Проверка перед передачей

```bash
pnpm install --frozen-lockfile
pnpm run typography:check
pnpm run build
pnpm run lint
```

После добавления текстов выполните `pnpm run typography:fix`: команда связывает союзы, короткие предлоги и тире со следующим словом неразрывным пробелом в исходниках страниц и текстовых данных. Анимированный заголовок сохраняет эти группы при переносах.

Секреты задаются через защищённое окружение или в панели интеграций. Заявки хранятся в SQLite в SMARTBUS_DATA_DIR, который на VPS размещается вне проекта. Файл `certs/russian_trusted_root_ca.pem` содержит публичный корневой сертификат, необходимый текущей интеграции с MAX.

## Материалы перед публичным запуском

- Подтвердить тарифы, характеристики и фотографии конкретных автобусов.
- Добавить номер лицензии и утверждённые файлы для скачивания.
- В четырёх юридических документах указан домен `s-bus.ru`. Согласовать тексты с ответственным специалистом.
- Подтвердить инфраструктуру хранения заявок и порядок удаления по сроку, указанному в политике и согласии.
- Проверить подключение MAX и доставку согласованной тестовой заявки после развёртывания.
- Предоставить реальные фотографии салонов, если они нужны для статей.

Иллюстрации автобусов в `public/media` являются концептуальными изображениями. Скриншоты приложения предоставлены заказчиком.

### Экраны ошибок и отсутствие интернета

- `app/not-found.tsx` показывает фирменную страницу для отсутствующего адреса. Next.js возвращает HTTP 404. Стандартный резервный ответ 500 генерируется из `pages/500.tsx`. Ошибки React перехватывают `app/error.tsx` и `app/global-error.tsx`.
- Экран `/offline` предлагает позвонить диспетчеру и проверить соединение через `/api/health`. При потере сети на открытой странице `SiteAvailability` показывает этот экран в диалоге. После успешной проверки соединения пользователь возвращается к заполненной форме.
- Сервис-воркер `public/sw.js` перехватывает навигацию после установки. При сетевом сбое он отдаёт `offline.html` со статусом 503. При ответах 4xx и 5xx, кроме штатного 404, он отдаёт `unavailable.html` с фактическим кодом, заголовком Retry-After при наличии и подходящим сообщением. Для первого открытия сайта при недоступном приложении веб-сервер может использовать `public/system/unavailable.html` как страницу ошибки.
- Кэш восстановления содержит обе статические страницы, `state.css`, `retry.js`, локальные шрифты BICUBIK и Garet, SVG-логотип, три SVG транспорта из футера и favicon. При изменении этих ресурсов поднимите версию `CACHE_NAME`. API, отправка форм и данные заявок идут напрямую в сеть.
- Проверить обе статические страницы можно по адресам `/system/offline.html` и `/system/unavailable.html`. После успешной проверки соединения на этих адресах открывается главная страница. При подстановке страницы сервис-воркером повторно открывается исходный адрес.
